# Contributing

Contributions that improve reproducibility, tests, documentation, or defensive analysis are welcome.

1. Create a focused branch.
2. Keep examples inside an offline, authorized test environment.
3. Run `pytest -q` and `ruff check attack.py tests scripts`.
4. Explain behavior changes and their security implications in the pull request.

Do not contribute live targets, credentials, private competition data, undisclosed vulnerabilities, or instructions aimed at unauthorized exploitation.
